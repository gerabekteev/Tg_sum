# Telegram-Саммаризатор (Фаза 1: Сборщик без LLM)

Этот проект представляет собой инструмент для автоматического и ручного сбора сообщений из вузовского (или любого другого) чата, в котором вы состоите, без необходимости иметь права администратора.

Управление всей системой осуществляется через удобного **Telegram-бота** с кнопками меню. Собранные сообщения сохраняются в `.txt` файлы в папку `dumps/` и присылаются вам файлом в чат с ботом.

Проект поддерживает запуск как локально на Python, так и через **Docker / Docker Compose**, что делает его готовым к быстрому переносу на VPS-сервер.

## ⚙️ Настройка (.env)

Перед запуском вам нужно настроить файл конфигурации. Откройте файл `.env` в текстовом редакторе и заполните следующие поля:

1. **`TELEGRAM_API_ID`** и **`TELEGRAM_API_HASH`**:
   * Перейдите на [my.telegram.org](https://my.telegram.org/), авторизуйтесь под своим аккаунтом.
   * Перейдите в раздел **API development tools** и создайте новое приложение.
   * Скопируйте `App api_id` и `App api_hash` в соответствующие строки `.env`.
2. **`TELEGRAM_PHONE`**: Номер вашего телефона, привязанный к Telegram-аккаунту (например, `+79991234567`), в международном формате.
3. **`BOT_TOKEN`**: Токен управляющего бота. 
   * Напишите [@BotFather](https://t.me/BotFather) в Telegram и выполните команду `/newbot`.
   * Задайте боту имя и юзернейм (например, `my_summary_control_bot`).
   * Скопируйте присланный API токен в `.env`.
4. **`ADMIN_ID`**: Ваш личный ID в Telegram (чтобы бот отвечал только вам). Узнать его можно, написав любое сообщение боту [@userinfobot](https://t.me/userinfobot) или [@username_to_id_bot](https://t.me/username_to_id_bot).
5. **`TARGET_CHAT`**: Юзернейм (например, `@target_group_username`) или ID (например, `-100123456789`) чата, откуда юзербот будет собирать сообщения. Юзербот должен состоять в этом чате.
6. **`DEFAULT_PERIOD_HOURS`**: Интервал автоматического сбора по расписанию в часах (например, `4` для сбора сообщений каждые 4 часа).
7. **`TIMEZONE`**: Ваш часовой пояс для корректного отображения времени в отчетах (например, `Europe/Moscow`). По умолчанию `UTC`.
8. **`AGY_CLI_PATH`**: Путь к исполняемому файлу Antigravity CLI (по умолчанию `agy`). На обеих системах (Windows, Linux) CLI обычно устанавливается как глобальная команда `agy` и доступна из системного PATH.

## 🐳 Запуск через Docker и Docker Compose (Рекомендуемый)

Это самый простой способ запуска. Вам не нужно устанавливать Python и библиотеки на свой компьютер. Нужен только установленный [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### Шаг 1. Сборка и первая интерактивная авторизация
Так как юзерботу при первом запуске необходимо ввести код подтверждения из Telegram, первый запуск должен быть **интерактивным** (в открытом терминале):

Откройте терминал/командную строку в папке проекта и выполните:
```bash
docker compose run --rm app
```
1. Контейнер соберется и запустится.
2. В консоли появится запрос кода подтверждения от Telegram (он придет вам внутри Telegram).
3. Введите код и нажмите Enter.
4. Если установлен облачный пароль (2FA) — введите его и нажмите Enter.
5. После успешного входа вы увидите сообщение: `Юзербот успешно авторизован!`.
6. Нажмите `Ctrl + C`, чтобы остановить интерактивный контейнер.

### Шаг 2. Запуск в фоновом режиме (постоянная работа)
Теперь, когда файлы сессий сохранены в вашей папке `sessions/` на компьютере, вы можете запустить бота в фоновом режиме:
```bash
docker compose up -d
```
Скрипт будет работать в фоне и автоматически перезапускаться при сбое или перезагрузке компьютера/сервера.

### Как смотреть логи контейнера:
```bash
docker compose logs -f
```

### Как остановить бота:
```bash
docker compose down
```

## 🐍 Локальный запуск через Python (Альтернативный)

Если вы не хотите использовать Docker, вы можете запустить скрипт напрямую на Python:

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите скрипт:
   ```bash
   python main.py
   ```
3. Пройдите авторизацию в консоли. Сессии сохранятся в папку `sessions/`.

## 🎮 Управление через Telegram

Откройте чат с вашим созданным ботом в Telegram и отправьте команду `/start`.
Бот пришлет приветственное сообщение и откроет клавиатуру с кнопками:

* **📥 За 1 час** / **📥 За 4 часа** / **📥 За 24 часа** — моментальный сбор сообщений за выбранный интервал. Бот сформирует текстовый файл со всеми сообщениями чата в хронологическом порядке и отправит его вам.
* **🔄 Собрать новые (авто)** — сбор всех новых сообщений, опубликованных в целевом чате с момента последнего успешного сбора (ручного или автоматического).
* **⚙️ Статус и настройки** — проверка состояния подключения, вывод информации о целевом чате, времени последнего сбора и ID последнего обработанного сообщения.

## 📂 Структура файлов проекта

* `Dockerfile` и `docker-compose.yml` — конфигурация для запуска в контейнере.
* `main.py` — главный файл запуска, объединяющий юзербота, интерфейсного бота и планировщик.
* `parser.py` — логика сбора сообщений и парсинга через Telethon (юзербот).
* `bot.py` — логика управления через бот-интерфейс и обработка нажатий кнопок.
* `config.py` — чтение переменных окружения из `.env`, создание служебных папок.
* `sessions/` — папка, где хранятся файлы сессий Telegram и состояние `state.json` (монтируется в Docker, сохраняет авторизацию).
* `dumps/` — папка, куда сохраняются `.txt` файлы со сборками сообщений (доступна и на вашем хост-компьютере при работе через Docker).
