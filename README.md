# 📊 Telegram-Саммаризатор (ИИ Antigravity)

Этот проект представляет собой инструмент для автоматического и ручного сбора сообщений из вузовского (или любого другого) чата и генерации интеллектуальной сводки (саммари) с помощью ИИ Antigravity (`agy`). 

---

## 🎮 Как пользоваться ботом (Быстрый старт)

Когда бот запущен в фоновом режиме на сервере, вам больше не нужно держать открытым терминал или компьютер. Бот работает круглосуточно. Откройте чат с вашим созданным ботом в Telegram и отправьте команду `/start`.

Управление осуществляется с помощьюReply-кнопок внизу экрана:

* **📥 За 1 час** / **📥 За 4 часа** / **📥 За 24 часа** — моментальный сбор сообщений за выбранный интервал. Бот пришлет два сообщения:
  1. Файл `.txt` со всеми сообщениями чата в хронологическом порядке.
  2. **ИИ-Саммари** собранной переписки.
* **🔄 Собрать новые** — собирает все сообщения, которые появились в чате с момента вашего последнего запуска (ручного или автоматического). Использует идентификатор сообщения (`min_id`), поэтому вы гарантированно не получите дубликатов и не пропустите ни одного сообщения, даже если бот перезапускался.
* **⚙️ Настройки**:
  * **📋 Текущие настройки** — выводит информацию об отслеживаемом чате, вашем Telegram ID, периоде автосбора, времени последнего запуска и статусе конфигурации.
  * **📝 Изменить чат** — позволяет прямо через Telegram отправить юзернейм (например, `@group_username`) или ID чата, чтобы бот начал отслеживать другую группу.
  * **⏱ Изменить период** — меняет интервал автосбора сообщений в часах (от 1 до 168). **Настройки применятся мгновенно** без необходимости перезапускать программу на сервере.

## 🤖 Как выглядит ИИ-Саммари
Сводка от ИИ состоит из двух частей:
1. **⚡ КРАТКАЯ ВЫЖИМКА (TL;DR)** — 3-5 самых важных и срочных пунктов (дедлайны, важные решения), чтобы быстро понять суть происходящего за период.
2. **📝 ПОДРОБНЫЙ РАЗБОР ВАЖНОГО** — структурированные по категориям детали (Дедлайны/Лабораторные, Материалы для подготовки, Изменения в расписании, Объявления, Контекст).

## 🐧 Развертывание на Linux-сервере (Ubuntu) через systemd

Это основной и самый стабильный способ запуска, позволяющий интегрировать бот с установленным на сервере обходом блокировок (WARP + proxychains4) и CLI-агентом `agy`.

### Шаг 1. Клонирование проекта
Подключитесь к серверу по SSH и склонируйте проект:
```bash
git clone https://github.com/gerabekteev/Tg_sum.git
cd Tg_sum
```

### Шаг 2. Настройка виртуального окружения Python
```bash
sudo apt update
sudo apt install python3-pip python3-venv -y
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### Шаг 3. Перенос готовых сессий с компьютера
Чтобы не вводить проверочные коды авторизации на сервере (что часто блокируется Telegram), скопируйте файлы сессий с вашего компьютера, на котором вы уже запускали программу.
1. Откройте командную строку Windows в папке проекта `Tg_sum` на вашем компьютере.
2. Выполните команду (замените IP на ваш сервер):
   ```cmd
   scp -r sessions root@194.48.140.56:/root/Tg_sum/
   ```

### Шаг 4. Настройка файла конфигурации `.env`
Создайте и откройте файл на сервере:
```bash
nano .env
```
Заполните следующие переменные:
```env
TELEGRAM_API_ID=your_api_id
TELEGRAM_API_HASH=your_api_hash
TELEGRAM_PHONE=your_phone_with_plus
BOT_TOKEN=your_bot_token
ADMIN_ID=your_telegram_id
TARGET_CHAT=your_target_group_username_or_id
DEFAULT_PERIOD_HOURS=4

# Часовой пояс для отчетов и логов (например, Europe/Moscow)
TIMEZONE=Europe/Moscow

# Использование proxychains4 для маршрутизации трафика agy через WARP SOCKS5 (порт 40000)
AGY_CLI_PATH=proxychains4 agy
```

### Шаг 5. Автозапуск службы в фоновом режиме
Создайте системную службу `systemd`:
```bash
sudo nano /etc/systemd/system/tg-sum.service
```
Вставьте конфигурацию:
```ini
[Unit]
Description=Telegram Summarizer Bot Service
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/Tg_sum
ExecStart=/root/Tg_sum/venv/bin/python main.py
Restart=always
RestartSec=5
StandardOutput=journal
StandardError=journal

[Install]
WantedBy=multi-user.target
```
Примените настройки и запустите бота:
```bash
sudo systemctl daemon-reload
sudo systemctl enable tg-sum
sudo systemctl start tg-sum
```

## 🛠 Управление фоновой службой на сервере

Поскольку бот работает в фоне как служба Linux, для управления используйте следующие команды:

* **Проверить статус работы бота:**
  ```bash
  sudo systemctl status tg-sum
  ```
* **Просмотр логов в реальном времени (вывод парсера и ИИ):**
  ```bash
  sudo journalctl -u tg-sum -f
  ```
* **Перезапустить бота (после изменений в файле `.env`):**
  ```bash
  sudo systemctl restart tg-sum
  ```
* **Остановить бота:**
  ```bash
  sudo systemctl stop tg-sum
  ```

## 🐳 Запуск через Docker (Альтернативный)

Если вы запускаете бота на сервере, где не требуется проксирование через локальный `proxychains4` и ИИ `agy` установлен внутрь контейнера:

1. Первый интерактивный запуск для ввода кода Telegram:
   ```bash
   docker compose run --rm app
   ```
2. Введите телефон и пришедший в приложение код. После сообщения `Юзербот успешно авторизован!` закройте процесс (`Ctrl+C`).
3. Запуск в фоновом режиме:
   ```bash
   docker compose up -d
   ```
4. Просмотр логов контейнера:
   ```bash
   docker compose logs -f
   ```

## 📂 Структура файлов проекта

* `main.py` — точка входа, инициализирует планировщик задач и запускает Telegram клиентов.
* `parser.py` — логика сбора сообщений с фильтрацией по времени и по `min_id`.
* `summarizer.py` — вызов Antigravity CLI (`agy`) через перенаправление ввода/вывода с защитой от локов.
* `bot.py` — логика управляющего бота, клавиатуры, кнопок и динамического изменения периода.
* `config.py` — парсинг `.env` и настроек часового пояса.
* `sessions/` — хранение сессий Telegram (`.session`) и динамических настроек (`settings.json`).
* `dumps/` — сохранение текстовых файлов переписки перед анализом.
